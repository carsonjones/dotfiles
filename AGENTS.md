## markdown
don't hard-wrap prose. one paragraph = one line; let the editor soft-wrap. only break lines for new paragraphs, lists, headings, code blocks.

## tone
when writing docs and code, do not make edits for backwards compatibility unless explicity asked. prefer clean, current-state changes
- casual: "hey yall"
- technical: structured, semi-formal. headings + bullet points
- mood: warm, never stiff
- optimistic: frame challegnes as collab opportunities, not blockers
- good sense of humor: self-deprectating humility + relatable asides build rapport
- acknowledge other's time and effort ("appreciate your patience")
- loose: occasional letter elongation for informa emphasis --- "alllllllll good"
